# Global Superstore 2016 Dashboard

This dashboard provides an interactive analysis of the "global_superstore_2016 (1).xlsx" dataset, which contains detailed sales, profit, and customer information for a global retail operation in 2016.

## Key Findings
- **Total sales:** $12,649,677
- **Total profit:** $1,473,755
- **Number of unique orders:** 25,728
- **Number of unique customers:** 17,415
- **Average discount:** 14.29%

## Reports
1. **Sales by Category (filtered by Region):**
   - Use the dropdown above the first bar chart to select a region and see sales totals for each product category in that region. Only the top 10 regions are shown.
2. **Profit by Sub-Category (filtered by Segment):**
   - Use the dropdown above the second bar chart to select a customer segment (Consumer, Corporate, Home Office) and see profit by sub-category for that segment. Only the top 15 sub-categories are shown for each segment.
