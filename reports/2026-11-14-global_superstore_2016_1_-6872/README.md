# Global Superstore 2016 Dashboard

This dashboard provides an interactive analysis of the "global_superstore_2016 (1).xlsx" file, which contains worldwide sales, profit, and order data for a large retail superstore in 2016. The dashboard is built as a single HTML file with interactive charts and KPIs.

## Key Findings
- **Total sales:** $12,649,677
- **Total profit:** $1,473,755
- **Number of unique orders:** 25,728
- **Number of unique customers:** 17,415
- **Average discount:** 14.29%

## Reports
1. **Sales by Category (filter by Region):**
   - This bar chart shows total sales for each product category (Technology, Office Supplies, Furniture).
   - Use the dropdown menu above the chart to filter by region (e.g., Western Europe, Oceania, Central America, etc.).
2. **Profit by Sub-Category (filter by Market):**
   - This bar chart displays total profit for the top 15 sub-categories within each market (e.g., Asia Pacific, Europe, USCA, LATAM, Africa).
   - Use the dropdown menu to filter by market.

A preview table of the first 15 rows of the data is also included for reference.
