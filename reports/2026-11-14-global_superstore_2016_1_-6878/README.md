# Global Superstore 2016 Dashboard

This dashboard presents an interactive analysis of the "Global Superstore 2016" dataset, which contains detailed sales, profit, and order information from a global retail operation. The data covers over 51,000 orders, including customer, product, and regional details.

## Key Findings
- **Total sales** were $12,649,677 across 25,728 unique orders and 17,415 customers.
- **Total profit** was $1,473,755, with an average discount of 14.29% per order.
- **Western Europe** was the most profitable region, generating $220,627 in profit.
- **Technology** was the top sales category, with $4,748,657 in sales.
- The **United States** had the most orders (9,994).

## Dashboard Features
- **Bar Chart:** Shows the top 15 sub-categories by sales. Use the "Category" dropdown to filter the bars by product category.
- **Pie Chart:** Displays the sales share by region. Use the "Segment" dropdown to filter the pie by customer segment.
- Both charts update instantly when you change their filters, allowing you to explore the data interactively.

The file `analysis.py` contains the full Python code used to generate this dashboard. All files are available in this GitHub folder.
