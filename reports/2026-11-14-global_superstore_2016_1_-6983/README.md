# Global Superstore 2016 Dashboard

This dashboard presents an interactive analysis of the "Global Superstore 2016" dataset, which contains worldwide sales, profit, and returns data for a large retail operation. The data covers orders, returns, and people involved in the sales process.

## Key Findings
- **Total sales** reached $12,649,677 across 25,728 unique orders.
- **Total profit** was $1,473,755, with an average discount of 14.29% per order.
- **Returned orders** accounted for 4.19% of all orders (1,079 returns).
- The **best-selling sub-category** was Phones ($1,708,924 in sales).
- The **most profitable segment** was Consumer ($753,342 in profit).
- **Western Europe** had the highest regional sales ($1,731,930).

## Dashboard Features
- **Bar Chart:** Shows the top 15 sub-categories by sales. Use the "Region" dropdown to filter results by region.
- **Pie Chart:** Displays profit distribution by segment. Use the "Order Priority" dropdown to filter by order priority.
- **KPIs** and **insights** are shown at the top, with a preview of the first 10 rows of the data below.

The dashboard is fully interactive—select different filters to explore how sales and profit vary by region and order priority.

The file `analysis.py` contains the complete Python script used to generate this dashboard. All files are available in this GitHub folder.
