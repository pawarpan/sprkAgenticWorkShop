# Global Superstore 2016 Orders Analysis

This dashboard presents an interactive analysis of 51,292 orders from the Global Superstore 2016 dataset. The data covers sales, profit, customers, and order details across 165 countries and multiple product categories.

## Key Findings
- **Total Sales:** $12,649,676.73
- **Total Profit:** $1,473,754.57
- **Top country by sales:** United States ($2,297,300.86)
- **Most common segment:** Consumer (26,519 orders)
- **Highest profit product:** Canon imageCLASS 2200 Advanced Copier ($25,199.93)

## Interactive Reports
1. **Sales by Category (filter by Region):**
   - This bar chart shows total sales for each product category. Use the dropdown to filter by region and see how sales vary across different parts of the world.
2. **Order Count by Country (filter by Segment):**
   - This bar chart displays the number of orders per country. Use the dropdown to filter by customer segment (Consumer, Corporate, Home Office) to explore order distribution.
